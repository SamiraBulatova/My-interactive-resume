# Интерактивное резюме

Одностраничный сайт-резюме, созданный в рамках вступительного задания.
Сайт содержит информацию обо мне, моём образовании, навыках, опыте и учебных проектах.

## Ссылка на сайт

🔗 [Открыть опубликованный сайт](https://SamiraBulatova.github.io/My-interactive-resume/)

## Что реализовано

- [x] Адаптивная вёрстка (проверено на 1440px, 768px, 375px)
- [x] Семантический HTML: `header`, `main`, `section`, `article`, `footer`, `nav`, `ul`
- [x] CSS без фреймворков, написан вручную
- [x] Flexbox и CSS Grid для раскладки
- [x] Интерактивный раздел «Навыки»:
  - фильтрация по категориям
  - поиск по названию (нечувствителен к регистру)
  - совместная работа фильтра и поиска
  - сообщение «Ничего не найдено»
- [x] Светлая и тёмная тема с сохранением в `localStorage`
- [x] Публикация через GitHub Pages

## Что не реализовано

- Всё из обязательной части выполнено.

## Технологии

- HTML5
- CSS3 (Flexbox, Grid, CSS-переменные)
- JavaScript (Vanilla JS)
- Google Fonts: DM Sans, Mulish
